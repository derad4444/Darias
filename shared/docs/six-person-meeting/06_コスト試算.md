# コスト試算（100% AI生成版）

> **最終更新**: 2026-09-16

会議はリクエストごとにその悩み（concern）へ沿って毎回新規生成される。過去に生成した会議の再利用は行わないため、1会議あたり常にフル生成コストが発生する。

## 💰 詳細コスト計算

### 前提条件

```
ユーザー数: 1,000人
プレミアム課金率: 5%
プレミアムユーザー: 50人
平均利用頻度: 月5回/人（プレミアム: 無制限）
```

---

## 📊 1. 1会議あたりのコスト

### 使用モデルと料金

```
【会議生成】gpt-4o-2024-11-20
入力: $2.50 / 1M tokens
出力: $10.00 / 1M tokens

【カテゴリ判定】gpt-4o-mini
入力: $0.150 / 1M tokens
出力: $0.600 / 1M tokens

為替レート: $1 = 150円
モデル単価の最終確認日: 2026年3月
```

`generateSixPersonMeeting.js` は会議生成・カテゴリ判定のどちらにも `max_tokens` を
指定していない。出力長はプロンプトの指示（発言数・文字数・JSON構造）だけで決まる。

---

### 入力トークン（実測ベース）

`createMeetingPrompt()` が実際に組み立てるプロンプトを
`generateSixPersonalities({O:4,C:4,E:2,A:4,N:3}, "female")` と
悩み「転職すべきか迷っている」（11文字）で生成して計測した実値。

```
【ユーザーメッセージ（createMeetingPrompt の戻り値）】
文字数: 4,976文字（絵文字を1文字として数えた場合。JS の .length では 4,981）
  うち日本語・絵文字など非ASCII: 2,376文字
  うちASCII（JSONひな形・英語キー・記号・改行）: 2,600文字

トークン換算（日本語 1.5文字/token、ASCII 約4文字/token）:
  2,376 ÷ 1.5 = 1,584 tokens
  2,600 ÷ 4   =   650 tokens
                ───────────────
                 2,234 tokens

【systemメッセージ】
"You are a JSON generator. Always respond with valid JSON only, no explanations or markdown."
91文字（全てASCII）≒ 23 tokens

入力合計: 約2,260 tokens
```

プロンプトの内訳（文字数）:

| 区分 | 文字数 | 備考 |
|-----|-------|------|
| 6人の性格特性（`buildPersonalityTraits()` の出力） | 551 | BIG5の数値ではなく日本語の特性文 |
| 悩み本文 | 11 × 2 | 【状況】と【重要な原則】の2箇所に埋め込まれる |
| カテゴリ別の結論指示 | 25〜84 | 最短は other（25文字）、最長は career（84文字） |
| 固定部分（原則・Phase構成・禁止表現・出力JSONひな形など） | 約4,300 | 悩みの長さによらず一定 |

プロンプト全体の長さはカテゴリにより 4,921文字（other）〜 4,981文字（career）。

> 悩みは最大500文字まで入力できる。悩み500文字のときプロンプトは5,959文字になり、
> 入力は約2,910 tokens（systemメッセージ込み）まで増える
> （悩み本文がプロンプト内に2回埋め込まれるため）。

> 全体を日本語レート（1.5文字/token）で換算すると約3,380 tokens になる。
> 実トークナイザによる計測は未実施のため、この範囲に収まると見ておく。

---

### 出力トークン（構造からの推定）

プロンプトが要求する出力JSONの構造から見積もった値。**実測ではない。**

```
【前提（プロンプトの指示・出力ひな形より）】
・rounds 3個、発言数は出力ひな形どおり 6 + 6 + 4 = 16発言
  （Phase指示は 5〜7 / 5〜7 / 4〜6 なので 14〜20発言の幅がある）
・1発言 = characterId / characterName / text(60〜120文字) / timestamp(ISO文字列)
・conclusion.summary 200〜300文字
・conclusion.recommendations 3項目

【text 90文字・summary 250文字で組んだJSONの実サイズ】
3,545文字（日本語 1,880文字 / ASCII 1,665文字）

トークン換算:
  1,880 ÷ 1.5 = 1,253 tokens
  1,665 ÷ 4   =   416 tokens
                ───────────────
出力合計: 約1,670 tokens
```

> JSONのキー名・タイムスタンプ・話者名がASCII/短い日本語で全体の約半分を占める。
> 発言数が20に増えると約2,000 tokens まで伸びる。

---

### 会議生成のコスト

```
入力: 2,260 tokens × $2.50 / 1M = $0.005650 ≈ 0.85円
出力: 1,670 tokens × $10.00 / 1M = $0.016700 ≈ 2.51円
─────────────────────────────────────────
小計: $0.02235 ≈ 3.35円/会議
```

### カテゴリ判定のコスト

Flutter は `concernCategory` を送らない（`meeting_datasource.dart` は
引数が null のときパラメータ自体を付けない）ため、この判定は**毎回実行される**。

```
プロンプト: 256文字（日本語126文字 / ASCII 130文字）≒ 117 tokens
出力: カテゴリIDのみ ≒ 2 tokens

入力: 117 tokens × $0.150 / 1M = $0.0000176 ≈ 0.003円
出力: 2 tokens × $0.600 / 1M ≈ 0円
─────────────────────────────────────────
小計: 約0.003円/会議
```

## 💡 10. コスト特性と最適化余地

### 現在のコスト特性

```
・会議は毎回その悩みに沿って新規生成される
・1会議あたり約3.4円が常に発生（再利用による割引はない）
・コストは利用回数に比例して線形に増加する
・出力トークン（約2.5円）が全体の約7割
```

### コスト削減の余地

```
・出力がコストの大半なので、発言数（現在16発言想定）や1発言の文字数
  （現在60〜120文字）の見直しが最も効果的
・timestamp は表示に使われていないが、出力JSONの各発言に含まれている
・カテゴリ判定はクライアントから concernCategory を渡せば省略できる
  （約0.003円/会議・現状は毎回実行される）
・入力プロンプトは約4,300文字が悩みに依存しない固定部分。
  同一プロンプトの繰り返しなのでプロンプトキャッシュの適用余地がある
・より安価なモデルへの切り替えは品質とのトレードオフ
```

## 📊 付録: カテゴリ別相性診断コスト

### 機能概要

フレンドとの BIG5 スコアを元に、4カテゴリ（友情・恋愛・仕事・信頼）それぞれについてAIがキャラクター会話を生成する機能。

```
【対象関数】diagnoseCompatibility (Cloud Function)
【モデル】gpt-4.1-mini
【呼出タイミング】ユーザーが各カテゴリの診断ボタンを押したとき（広告視聴後）
```

---

### 1カテゴリあたりのトークン数（推定）

```
【入力トークン】
- システムプロンプト（カテゴリ説明・JSON形式指示）: 約220 tokens
- BIG5口調プロフィール（双方分）: 約120 tokens
- スコアと生成指示: 約40 tokens
合計入力: 約380 tokens

【出力トークン（max_tokens: 600）】
- 会話4〜5ターン + comment + advice（JSON）: 約250 tokens

【コスト計算（gpt-4.1-mini）】
入力: 380 tokens × $0.40 / 1M = $0.000152 ≈ 0.023円
出力: 250 tokens × $1.60 / 1M = $0.000400 ≈ 0.060円
─────────────────────────────────────────
小計: 約0.083円/カテゴリ（≈¥0.08）

参考: gpt-4.1-mini料金（2026年4月確認）
入力: $0.40 / 1M tokens
出力: $1.60 / 1M tokens
```

> **6人会議との比較**: 6人会議は gpt-4o-2024-11-20 で毎回新規生成し約3.4円/回。
> 相性診断は gpt-4.1-mini で約0.083円/カテゴリ（約1/40のコスト）。
