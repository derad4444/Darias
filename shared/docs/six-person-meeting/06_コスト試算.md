# コスト試算（100% AI生成版）

> **最終更新**: 2026-08-06（自分会議の「次のステップ」を廃止し、結論を summary + recommendations の2要素に変更）

会議はリクエストごとにその悩み（concern）へ沿って毎回新規生成される。過去に生成した会議の再利用は行わないため、1会議あたり常にフル生成コストが発生する。

## 💰 詳細コスト計算

### 前提条件

```
ユーザー数: 1,000人
プレミアム課金率: 5%
プレミアムユーザー: 50人
平均利用頻度: 月5回/人（プレミアム: 無制限）
```

## 📊 1. 1会議あたりのコスト（毎回新規生成）

### 使用モデルと料金（2026年3月時点）

```
【会議生成】gpt-4o-2024-11-20
入力: $2.50 / 1M tokens
出力: $10.00 / 1M tokens

【カテゴリ判定】gpt-4o-mini
入力: $0.150 / 1M tokens
出力: $0.600 / 1M tokens

為替レート: $1 = 150円
```

### 1会議あたりのトークン数（推定値）

#### 100% AI生成（脚本家アプローチ）

> トークン数は `sixPersonMeetingTemplates.js` のプロンプト構造からの推定値。厳密な値は実測が必要（要実測）。プロンプトには悩み（concern）・カテゴリ別結論指示・6人分の性格特性・出力JSONひな形が含まれる。

```
【会議生成トークン（gpt-4o-2024-11-20）】
入力トークン: 約1,246 tokens（推定・要実測）
- ユーザーの悩み: 約50 tokens
- 統計データ: 約100 tokens
- プロンプト（脚本家アプローチ）: 約1,096 tokens

出力トークン: 約687 tokens（推定・要実測）
- 会話3ラウンド（Phase制）: 約550 tokens
- 結論（summary + recommendations）: 約137 tokens

コスト計算（会議生成）:
入力: 1,246 tokens × $2.50 / 1M = $0.003115 ≈ 0.467円
出力: 687 tokens × $10.00 / 1M = $0.006870 ≈ 1.031円
─────────────────────────────────────────
小計: $0.009985 ≈ 1.498円/会議

【カテゴリ判定（gpt-4o-mini）- concernCategory 未指定時のみ】
入力: ~200 tokens × $0.150 / 1M = $0.000030 ≈ 0.005円
出力: ~5 tokens × $0.600 / 1M = $0.000003 ≈ 0.000円
─────────────────────────────────────────
小計: 約0.005円/判定

合計: 約1.50円/会議（毎回このコストが発生）
```

## 📊 付録: カテゴリ別相性診断コスト（2026-04-17 追加）

### 機能概要

フレンドとの BIG5 スコアを元に、4カテゴリ（友情・恋愛・仕事・信頼）それぞれについてAIがキャラクター会話を生成する機能。

```
【対象関数】diagnoseCompatibility (Cloud Function)
【モデル】gpt-4.1-mini
【呼出タイミング】ユーザーが各カテゴリの診断ボタンを押したとき（広告視聴後）
```

---

### 1カテゴリあたりのトークン数（推定）

```
【入力トークン】
- システムプロンプト（カテゴリ説明・JSON形式指示）: 約220 tokens
- BIG5口調プロフィール（双方分）: 約120 tokens
- スコアと生成指示: 約40 tokens
合計入力: 約380 tokens

【出力トークン（max_tokens: 600）】
- 会話4〜5ターン + comment + advice（JSON）: 約250 tokens（実測値）

【コスト計算（gpt-4.1-mini、日本語1文字≒1〜1.5 tokens）】
入力: 380 tokens × $0.40 / 1M = $0.000152 ≈ 0.023円
出力: 250 tokens × $1.60 / 1M = $0.000400 ≈ 0.060円
─────────────────────────────────────────
小計: 約0.083円/カテゴリ（≈¥0.08）

参考: gpt-4.1-mini料金（2026年4月時点）
入力: $0.40 / 1M tokens
出力: $1.60 / 1M tokens
```

> **6人会議との比較**: 6人会議は gpt-4o-2024-11-20 で毎回新規生成し約1.50円/回。
> 相性診断は gpt-4.1-mini で約0.083円/カテゴリ（約1/20のコスト）。

---

### キャッシュ効果

```
【キャッシュキー】 {big5Fingerprint1}|{big5Fingerprint2}_{category}
【ヒット時コスト】OpenAI API呼出なし → 実質0円

キャッシュヒット時の合計コスト:
Firestore読み取り: 1 read × $0.06/100K = 約0.00009円
Firestore書き込み: 1 write × $0.18/100K = 約0.00000027円
Cloud Functions: 約0.00005円
─────────────────────────────────────────
合計: 約0.0001円/カテゴリ（無視できるレベル）
```

> **備考**: 相性診断は BIG5 の組み合わせをキーにキャッシュ再利用する（6人会議は毎回新規生成でキャッシュ再利用しない点が異なる）。
> ただしキャッシュミスでも1カテゴリ約0.083円と安価。
