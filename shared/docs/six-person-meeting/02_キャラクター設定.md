# 6人のキャラクター設計

> **最終更新**: 2026-09-16

ユーザーのBIG5性格データ（1〜5のスコア）を基に、6つの異なる視点を持つ「自分」を生成する。

生成関数は `shared/functions/src/utils/sixPersonMeeting.js` の `generateSixPersonalities(userBig5, gender)`。
返すのは `{id, name, icon, catchphrase, description, big5, gender, position}` の配列。

**重要**: プロンプトにはBIG5の数値そのものは渡らない。各キャラクターの `big5` を
`shared/functions/src/prompts/templates.js` の `buildPersonalityTraits()` に通し、
日本語の「性格特性」文に変換したものだけを渡す（チャットの返答生成と同じ方式）。

`buildPersonalityTraits()` の変換基準:

| 特性 | スコア4以上 | スコア2以下 |
|-----|-----------|-----------|
| 開放性 | 新しい体験や創造を好む | 安定した慣れた環境を好む |
| 誠実性 | 計画的でルーティンや目標達成を大切にする | 柔軟でゆるやかなペースを好む |
| 外向性 | 人との交流が活力源の社交的な性格 | 一人の静かな時間を大切にする |
| 協調性 | 思いやりがあり仲間との協力を重んじる | 自分軸を大切にする |
| 神経症傾向 | 感受性が豊かでセルフケアを大切にする | 感情が安定していてストレスに強い |

どれにも当てはまらない場合は「バランスの取れた性格」。

## 1️⃣ 今の自分

### 基本情報
- **ID**: `original`
- **アイコン**: 🧑（アプリ内表示: 人物アイコン・青）
- **名前**: 今の自分
- **キャッチコピー**: 「慎重派の分析家」
- **説明**: いつものあなた。リスクを考えてデータを重視する性格。

### BIG5の変換
```javascript
{
  openness: userBig5.openness,
  conscientiousness: userBig5.conscientiousness,
  extraversion: userBig5.extraversion,
  agreeableness: userBig5.agreeableness,
  neuroticism: userBig5.neuroticism,
}
// ユーザーのスコアをそのまま使う
```

### 発言スタイル（プロンプトの指示）
「防御的だが、徐々に本音を明かす。神経症傾向の値に応じた不安・恐れを自然に表現」

### 配置
- **左側**（慎重派グループ / `position: "left"`）

## 2️⃣ 真逆の自分

### 基本情報
- **ID**: `opposite`
- **アイコン**: 🔄（アプリ内表示: 同期アイコン・オレンジ）
- **名前**: 真逆の自分
- **キャッチコピー**: 「自由奔放な冒険家」
- **説明**: あなたとは正反対の性格。大胆で即断即決タイプ。

### BIG5の変換
```javascript
{
  openness: 6 - userBig5.openness,
  conscientiousness: 6 - userBig5.conscientiousness,
  extraversion: 6 - userBig5.extraversion,
  agreeableness: 6 - userBig5.agreeableness,
  neuroticism: 6 - userBig5.neuroticism,
}
// 1〜5のスケールを中心（3）で反転する
// 例: 4 → 2、2 → 4、5 → 1
```

### 発言スタイル（プロンプトの指示）
「挑発的だが前向き。行動を促す。誠実性が低く直感で動く」

### 配置
- **右側**（行動派グループ / `position: "right"`）

## 3️⃣ 理想の自分

### 基本情報
- **ID**: `ideal`
- **アイコン**: ✨（アプリ内表示: 星アイコン・紫）
- **名前**: 理想の自分
- **キャッチコピー**: 「冷静な完璧主義者」
- **説明**: バランスが取れた成長した姿。客観的に物事を見る。

### BIG5の変換
```javascript
{
  openness: Math.max(userBig5.openness, 4),
  conscientiousness: Math.max(userBig5.conscientiousness, 4),
  extraversion: optimizeToMiddle(userBig5.extraversion, 3.5),
  agreeableness: Math.max(userBig5.agreeableness, 4),
  neuroticism: Math.min(userBig5.neuroticism, 2), // 低い = 情緒安定
}

// optimizeToMiddle: 目標値（3.5）へ1段階だけ近づける
function optimizeToMiddle(value, target) {
  if (value < target) return Math.min(value + 1, 5);
  if (value > target) return Math.max(value - 1, 1);
  return value;
}
```
開放性・誠実性・協調性は最低でも4に引き上げ、神経症傾向は最大でも2に抑える。
外向性だけは中央値へ寄せる（高すぎても低すぎても3.5側へ1段階動かす）。

### 発言スタイル（プロンプトの指示）
「冷静に全体を見て、新しい選択肢を示す。感情に流されない」

> プロンプトの【禁止表現リスト】により「バランスを取る」「両方の視点から考える」
> 「どちらも一理ある」といった曖昧な締め方は使わせない。

### 配置
- **左側**（慎重派グループ / `position: "left"`）

## 6️⃣ 未来の自分（70歳）

### 基本情報
- **ID**: `wise`
- **アイコン**: 👴（アプリ内表示: 高齢者アイコン・茶 #996633）
- **名前**: 未来の自分（70歳）
- **キャッチコピー**: 「達観した人生の先輩」
- **説明**: 70歳になったあなた。長い人生経験から冷静にアドバイスしてくれる。

### BIG5の変換
```javascript
{
  openness: Math.max(userBig5.openness - 1, 2),          // やや保守的
  conscientiousness: Math.min(userBig5.conscientiousness + 0.5, 5),
  extraversion: Math.max(userBig5.extraversion - 1, 2),  // 落ち着く
  agreeableness: Math.min(userBig5.agreeableness + 1, 5), // 寛容
  neuroticism: Math.min(userBig5.neuroticism + 1.5, 5),  // 達観
}
```
神経症傾向は引き上げられるため、`buildPersonalityTraits()` では
「感受性が豊かでセルフケアを大切にする」側の特性文になりやすい。

### 発言スタイル（プロンプトの指示）
「達観した視点で、時間軸を広げる。『後悔するか・しないか』で語る」

### 配置
- **左側**（慎重派グループ / `position: "left"`）

## 🗣️ 会話の組み立て

会話はプロンプトの Phase 構成に沿って1回のAI呼び出しでまとめて生成される。
発言順は固定せず、前の発言を受けた返答になるよう指示している。

| Phase | 目的 | 発言数の指示 |
|-------|-----|------------|
| Phase 1 | 悩みの本質を明らかにする | 5〜7発言 |
| Phase 2 | 異なる価値観を激しくぶつける | 5〜7発言 |
| Phase 3 | 対立を統合し明確な答えを出す | 4〜6発言 |

各発言は60〜120文字程度。1発言ごとに `characterId` / `characterName` / `text` / `timestamp` を持つ。

### 禁止表現（プロンプトで明示的に排除）
- 「〜すべき」「〜が大切」「〜が重要」
- 「バランスを取る」「両方の視点から考える」「どちらも一理ある」
- 「データに基づく」「統計的に」「〜によると」
- 「慎重に検討」「計画的に」「段階的に」
- その他、教科書的・模範解答的な一般論

### 推奨表現
- 問いかけ（「〜って本当？」「なんで？」）
- 具体的な経験の参照（「前にも〜だったよね」）
- 個人的な意見（「私は〜と思う」「僕なら〜する」）
- 反論・別視点（「でもさ、〜じゃない？」）
- 感情表現（「怖い」「ワクワクする」「焦る」「もどかしい」）

## 🗂️ 事前計算とバックフィル

6人分のデータは `characters/{characterId}/details/current` の `sixPersonalities` に
保存されていればそれを使い、無ければ会議生成時にその場で計算する。

未保存のユーザーを埋めるため、`backfillSixPersonalities`（毎日3時 JST の
スケジュール関数）が `analysis_level == 100` の `details` を走査して
`sixPersonalities` を補完する。
