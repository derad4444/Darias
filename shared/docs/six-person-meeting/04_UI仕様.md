# UI/UX仕様

## 🗺️ 画面遷移フロー

```
MainShellScreen（5タブ）
├─ ホームタブ
│  └─ チャットで悩みを話す
│     └─ 自分会議の提案バナーを表示
│        └─ [開く] → 自分会議タブへ切り替え
│
└─ 自分会議タブ（meetingTabIndex）
   ├─ 未解放（signalCount < 30） → ロック画面（進捗を表示）
   ├─ 悩みテキスト入力
   ├─ 生成中（ローディング）
   └─ 会議室 → 会話表示 → 統合レポート
      └─ [完了] → 結論をチャットへ引き継ぎ、ホームタブへ戻る
```

自分会議はタブの中身なので、単独ルート（`/meeting`）は持たない。

✅ **Flutter実装**: `flutter/lib/presentation/screens/meeting/meeting_screen.dart`

---

## 📱 画面詳細設計

### 1. 入口

- 下部タブバーの2番目「自分会議」から開く（`main_shell_screen.dart` の `meetingTabIndex`）
- チャットの返信で悩みが検出された場合、ホーム下部に提案バナーを表示
  - **表示条件**: `classifyAndExtract` 由来の `meetingSuggested` かつ `signalCount >= 30`
  - [開く] を押すと自分会議タブへ切り替わる
- **解放条件**: `signalCount >= 30`（性格タイプが確定するライン）。未解放のあいだ、自分会議タブは
  トピック入力の代わりに進捗を示すロック画面を表示する

---

### 2. 入力画面（input フェーズ）

- 悩みテキストエリア（自由入力）
- カテゴリは自動検出（サーバー側 `detectConcernCategory()`）
- 相談ボタン（テキスト空の場合はdisabled）

---

### 3. 6人会議画面（MeetingScreen）

#### 画面構成

```
┌─────────────────────────────────┐
│ ← 💭 6人会議                     │
├─────────────────────────────────┤
│                                 │
│  [Phase: introduction]          │
│  6キャラクターのプロフィール表示  │
│  → 「会議を始める」ボタン         │
│                                 │
│  [Phase: searching]             │
│  各キャラクターの調査中アニメーション│
│  進捗チェックマーク表示           │
│                                 │
│  [Phase: conversation]          │
│  チャット形式でメッセージ順次表示  │
│  左側: 慎重派 (青背景)            │
│  右側: 行動派 (オレンジ背景)      │
│  [結論へスキップ] ボタン          │
│                                 │
│  [Phase: conclusion]            │
│  統合レポート表示                 │
│                                 │
└─────────────────────────────────┘
```

---

### 4. 統合レポート（conclusion フェーズ）

✅ **実装済み** (`meeting_screen.dart` の `_buildConclusion()`)

実装済み内容：
- 結論サマリー（黄色背景）
- アドバイス（複数件・オレンジ背景）
- 共有ボタン（緑）: `share_plus` の `Share.share()` を使用。詳細仕様は [`SNS共有仕様書.md`](../functions/SNS共有仕様書.md) 参照
- ★5段階評価ダイアログ（`_showRatingDialog()`）

## 🎨 デザインガイドライン

### カラー
- 左側メッセージ（慎重派）: 青系
- 右側メッセージ（行動派）: オレンジ系

### アニメーション
- メッセージ表示間隔: 2.5〜5秒（メッセージ長に応じて動的調整）
  - ベース: 2.5秒
  - 追加: 1文字あたり0.017秒
  - 上限: 5秒
- メッセージのスライドイン（左右の方向に応じてフェードイン）
- スキップ機能で結論へジャンプ
