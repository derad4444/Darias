# 自分会議（6人会議）機能 - 実装ガイド

> **最終更新**: 2026-09-16

## ✅ 実装コンポーネント

### バックエンド（Cloud Functions）

#### 1. ユーティリティ関数
**ファイル**: `shared/functions/src/utils/sixPersonMeeting.js`

会議フローで使われる関数:
- `generateSixPersonalities(userBig5, gender)` — 6つの性格パターン生成
- `optimizeToMiddle(value, target)` — 値を目標値へ1段階近づける（理想の自分の外向性に使用）

同じファイルに `calculateSimilarity` / `generatePersonalityKey` /
`getCategoryDisplayName` / `detectConcernCategory`（キーワードによるカテゴリ推定） /
`calculateRoundCount` も定義されているが、会議生成のフローからは呼ばれていない。
カテゴリ判定は `detectConcernCategoryWithAI`（gpt-4o-mini）が担当する。

#### 2. 会議プロンプト
**ファイル**: `shared/functions/src/prompts/sixPersonMeetingTemplates.js`

- `getCategoryConclusion(category, concern)` — カテゴリ別の結論指示
  （career / romance / money / health / family / future / hobby / study / moving / other）
- `createMeetingPrompt(concern, category, personalities, statsData)` — 会議生成プロンプト
  - 各キャラクターのBIG5を `buildPersonalityTraits()`（`prompts/templates.js`）で
    日本語の性格特性文に変換して埋め込む
  - Phase構成・禁止表現リスト・推奨表現・出力JSONひな形を含む

#### 3. メインCloud Function
**ファイル**: `shared/functions/src/functions/generateSixPersonMeeting.js`

- `generateOrReuseMeeting` — メイン関数（毎回その悩みに沿って新規生成）
- `detectConcernCategoryWithAI` — gpt-4o-mini によるカテゴリ判定
- `checkPremiumStatus` / `getMeetingUsageCount` — 利用制限
- `checkMonthlyMeetingCount` / `incrementMonthlyMeetingCount` — 月間カウント記録
- `calculateStatsFromAnalysis` — `PersonalityStatsMetadata/summary` から統計算出
- `generateConversationWithAI` — gpt-4o-2024-11-20 で会話生成
- `backfillSixPersonalities` — 毎日3時（JST）の補完スケジューラ

`searchMeetingCache` は定義されているが呼び出されておらず、`cacheResult` は常に `null`。

#### 4. 関数登録
**ファイル**: `shared/functions/index.js`

```javascript
Object.defineProperty(exports, "generateOrReuseMeeting", {
  get: () => require("./src/functions/generateSixPersonMeeting").generateOrReuseMeeting,
  enumerable: true,
});
```

#### 5. Firestoreインデックス
**ファイル**: `firestore.indexes.json`

```json
{
  "collectionGroup": "shared_meetings",
  "queryScope": "COLLECTION",
  "fields": [
    {"fieldPath": "personalityKey", "order": "ASCENDING"},
    {"fieldPath": "concernCategory", "order": "ASCENDING"},
    {"fieldPath": "usageCount", "order": "DESCENDING"}
  ]

```
`personalityKey ASC, usageCount DESC` のインデックスも定義されている。
どちらも再利用クエリ用であり、現状は使われていない。

## 🧪 テスト手順

### 1. ローカルエミュレータでのテスト

```bash
firebase emulators:start

curl -X POST http://localhost:5001/my-character-app/asia-northeast1/generateOrReuseMeeting \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "userId": "test_user",
      "characterId": "test_character",
      "concern": "転職すべきか迷っています",
      "concernCategory": "career"
    }
  }'
```

> 本番の関数は `enforceAppCheck: true`。実機・シミュレータからの呼び出しでは
> App Check のトークンが必要になる。

### 2. シミュレータでのテスト

1. `flutter run -d "iPhone 16 Pro"` でシミュレータを起動
2. ログイン
3. 下部タブバーの「自分会議」を開く
4. `signalCount` が30未満ならロック画面が出ることを確認
5. 悩みを入力して「会議を開始」
6. 会話アニメーションと「結論へ」スキップを確認
7. 結論・アドバイス・共有を確認
8. 「完了」でホームに戻り、キャラクターが結論に反応することを確認
9. 履歴画面の「会議」タブから過去の会議を閲覧・共有・削除

### 3. 動作確認項目

✅ **解放条件**
- `signalCount < 30` ではロック画面と進捗バーが出る
- `signalCount >= 30` でトピック入力に切り替わる

✅ **無料ユーザー**
- 1回のみ利用可能
- 2回目はアップグレードダイアログ
- 使用回数バナーが「無料プランでは1回のみ利用可能」→「利用制限に達しました」に変わる

✅ **プレミアムユーザー**
- 無制限利用可能
- 使用回数バナーとバナー広告が出ない

✅ **毎回新規生成**
- 同じユーザーでも呼び出すたびに、その悩みに沿った新しい会議が生成される
- 同じ悩みでも内容は毎回変わりうる（temperature 0.8）
- 「再利用」バッジは出ない（`cacheHit` が常に false のため）

✅ **UI/UX**
- メッセージがメッセージ長に応じて2.5〜5秒間隔で表示
- 「結論へ」で残りを一括表示して結論へジャンプ
- 共有で結論カードのPNGとテキストが渡る

✅ **履歴機能**
- 過去の会議一覧表示・相談内容での絞り込み
- 詳細閲覧・共有・削除が可能

## 🐛 トラブルシューティング

### エラー: "OpenAI API key not configured"

```bash
firebase functions:secrets:set OPENAI_API_KEY
```

### エラー: `AI returned invalid JSON`

`generateConversationWithAI` が受け取った内容をJSONとしてパースできなかった場合に投げる。
ログの `contentPreview`（先頭500文字）で実際の応答を確認する。
フォールバックの会話は用意していないため、この場合ユーザーには生成失敗が返る。

### エラー: "キャラクターデータが見つかりません"（not-found）

`users/{userId}/characters/{characterId}/details/current` が存在しないときに発生する。
`confirmedBig5Scores` / `personalityKey` が入っているか確認する。

### 「無料ユーザーは1回のみ利用可能です」が想定外に出る

`meeting_history` の件数が1以上になっている。履歴を削除すれば再び利用できる。

### 会議タブがロック画面のまま

`signalCount` が30未満。チャットを続けて性格タイプを確定させる必要がある。
