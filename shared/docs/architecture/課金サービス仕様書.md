**キャラクター返信のトークン内訳（1回あたり・実測値）:**

送信メッセージ構成:
```
[system] 性格特性テキスト + 性別 + 指示文 .............. ~420 tokens（最優先ルール含む）
[user/assistant] 会話履歴（max 2往復 × 200字） ......... ~67×4 tokens
[user]   現在のメッセージ（チャット入力欄は100字上限）.... ~67 tokens
---
入力合計（実測値）: ~514〜571 tokens
出力（実測値）: ~65〜80 tokens（日本語 ~100〜120文字）
max_completion_tokens: 200（phase 1）/ 250（phase 2）/ 350（phase 3）
```

| | 無料（gpt-4o-mini） | プレミアム（gpt-4o） |
|---|---|---|
| 入力 540 tokens（実測平均） | $0.000081 | $0.001350 |
| 出力 80 tokens（実測平均） | $0.000048 | $0.000800 |
| **合計** | **≒¥0.025** | **≒¥0.42** |

**自分会議のフォローアップだけコストが上がる:**

会議の「完了」を押した直後、結論をそのまま `generateCharacterReply` に送る経路がある
（`home_screen.dart` `_triggerMeetingFollowup`）。この1回だけメッセージが長い。

- 送信内容: `【自分会議の結論】`（9字）＋ 結論サマリ（`sixPersonMeetingTemplates.js` の指示で 200〜300字）＝ 最大 309字
- `generateCharacterReply.js` の `USER_MESSAGE_MAX_CHARS` は **400字**。309字は全文が通る
- 309字 ÷ 1.5字/token ＝ **~206 tokens**（通常チャットの ~67 tokens に対し +139）

| | 無料（gpt-4o-mini） | プレミアム（gpt-4o） |
|---|---|---|
| 入力 679 tokens | $0.000102 | $0.001698 |
| 出力 80 tokens | $0.000048 | $0.000800 |
| **合計** | **≒¥0.029** | **≒¥0.49** |

発生頻度は**会議1回につき1回**（無料は生涯1回、プレミアムは会議のたび）。通常チャットの単価は変わらない。

> 上限を100字にしていた頃は、結論が文の途中で切れた状態でAIに渡り、AIが「返答」ではなく
> 「切れた文の続き」を書いてしまう不具合があった。400字はこれを避けるための値。

※ gpt-4o-miniはreasoningなし。応答速度1〜3秒（gpt-5-miniは6〜70秒で不安定だった）。

**フレンドへの質問 / 相性診断のトークン内訳（1回あたり・推定値）:**

```
[system] 会話生成ルール + JSONスキーマ ................. ~280 tokens

[user]   相手キャラの口調情報 ......................... ~55 tokens

---
入力合計（推定最大値）: ~450 tokens

```

#### Google Play Billing Library のバージョン要件

Google Play は**バージョン 8.0.0 以降の使用を必須**としている（**2026年8月31日**以降、これを満たさないアプリはアップデートが承認されない）。

| 項目 | 現在の値 |
|------|---------|
| `in_app_purchase`（`flutter/pubspec.yaml`） | `^3.3.0` |
| `in_app_purchase_android`（解決版） | `0.5.0` |
| **Google Play Billing Library** | **8.0.0** ✅ 要件を満たす |

- Billing Library のバージョンは Flutter プラグイン `in_app_purchase_android` が決定する（同パッケージの `android/build.gradle.kts` が `com.android.billingclient:billing` を宣言）。アプリ側の `build.gradle.kts` で直接指定はしていない。
- 対応表: `in_app_purchase_android` **0.4.x → Billing 7.1.1** / **0.5.x → Billing 8.0.0**。`in_app_purchase` **3.3.0** 以上で 0.5.x が入る。
- `0.5.0` の破壊的変更で `queryPurchaseHistory` / `queryPurchaseHistoryAsync` が削除された（本アプリでは未使用のため影響なし）。
- **バージョン9について**: Google は v9 を推奨しているが、Flutter 公式プラグインは最新の `in_app_purchase_android 0.5.2` でも Billing 8.0.0 のままで、v9 対応版は未リリース。また `0.5.0+1` 以降は Flutter 3.44 / Dart 3.12 以上が必要（本プロジェクトは Flutter 3.38.7 のため 0.5.0 が上限）。8.0.0 で要件は満たしている。
- **検証方法**: ビルド済みAABに実際に含まれるバージョンは以下で確認できる。

```bash
unzip -p build/app/outputs/bundle/release/app-release.aab \
  BUNDLE-METADATA/com.android.tools.build.libraries/dependencies.pb | strings -a -n 3 | grep -A3 billing
# → com.android.billingclient / billing / 8.0.0
```
