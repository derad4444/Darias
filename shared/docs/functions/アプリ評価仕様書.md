# DARIAS アプリ評価（ストアレビュー）仕様書

**最終更新日**: 2026-08-11

---

## 概要

App Store / Google Play の評価を、**アプリを離れずに**依頼する仕組み。
`in_app_review` パッケージでOS標準のレビュー画面をアプリ内に重ねて表示する。

**強制しない。** 「また今度」でも、ポップアップの外側をタップしても閉じられる。

---

## なぜ自前のポップアップを1枚挟むのか

**iOSの評価ダイアログは1年に3回までしか表示できない**（`SKStoreReviewController` の仕様）。
4回目以降はOSが黙って握り潰す。しかも**表示されたか・評価されたかをアプリ側から
知る方法がない。**

いきなりOSのダイアログを呼ぶと、評価する気のない人にも貴重な枠を消費してしまう。
そこで先に自前のポップアップで意思を確認し、**「評価する」を押した前向きな人にだけ
枠を使う。**

```
┌────────────────────────────┐
│         🎉                 │
│   おめでとうございます！      │
│                            │
│  「先延ばし」を克服しました。  │
│   ここまで向き合えたのは、    │
│   あなたの力です。           │
│                            │
│  よろしければ、ストアでの評価で  │
│  応援していただけると嬉しいです。│
│                            │
│  [ また今度 ]   [ ★ 評価する ]│
└────────────────────────────┘
        ↓「評価する」のときだけ
   OS標準の評価画面（アプリ内に重なる）
```

## 表示する場面

| # | 場面 | 実装箇所 | 追加条件 |
|---|------|---------|---------|
| 1 | **自分会議の結論表示後** | `meeting_screen.dart` `_maybeAskReview` | 通算**3回目以降**の会議 |
| 2 | **性格タイプの進化** | `home_screen.dart`（進化ダイアログを閉じた後） | なし |
| 3 | **ダンジョン初踏破** | `roguelike_result_screen.dart` `_maybeAskReview` | **初踏破のみ**（2回目以降は出さない） |

いずれも**ユーザーが最も満足している瞬間**。会議は頻度が高いので回数で絞り、
他の2つは元々レアなので共通条件だけで出す。

結論や演出を読む時間を取ってから出す（会議3秒 / ダンジョン4秒 / 進化0.8秒）。

---

## 共通の表示条件（`AppReviewService.shouldAsk`）

すべて満たしたときだけ表示する。

- **まだ評価していない**（一度「評価する」を押したら二度と出さない）
- **「また今度」の待機期間が明けている**
- **インストールから3日以上**（体験が浅いうちは判断材料がない）
- Web版では出さない（ストア評価が無い）

### 「また今度」を押した後

断られるほど間隔を空け、3回断られたら二度と聞かない。

| 何回目の「また今度」 | 次に出るまで |
|------------------|------------|
| 1回目 | **30日後** |
| 2回目 | **90日後** |
| 3回目 | **二度と出さない** |

**ポップアップの外側をタップして閉じた場合も「また今度」と同じ扱い**にする
（無視されたのに何度も出すのは迷惑なため）。

## 「評価する」を押したときの挙動（2段階）

### 1段目: 星の評価（アプリ内・離脱なし）

OS標準の評価画面がアプリ内に重なって出る。**ストアには飛ばない。**

上限に達しているとOSは何も表示しないが、**表示されたか判別できない**ため、
押した時点で完了として扱う（`_kDone` を立てる）。

### 2段目: 文章レビューのお願い（任意・ストアへ移動）

**アプリ内の評価画面では星しか付けられず、文章のレビューは書けない。**
文章レビューは検索順位や新規ユーザーの判断に効くため、
星を付けてくれた人にだけ続けてお願いする（`_askWrittenReview`）。

```
┌────────────────────────────┐
│           🙏               │
│    ありがとうございます      │
│                            │
│  もしよろしければ、ひとこと   │
│  感想もいただけると励みに     │
│  なります。                 │
│                            │
│  ストアのページが開きます。   │
│                            │
│ [このままでいい] [✏️ 感想を書く]│
└────────────────────────────┘
        ↓「感想を書く」のときだけ
   openStoreListing()（アプリを離れる）
```

- **1段目の完了を検知できない**ため、`requestReview()` の**5秒後**に出す
- 断りやすい見せ方にする（アプリを離れる操作のため）
- 「このままでいい」なら何もしない。1段目の星評価は既に完了している

> **高評価の人だけストアへ誘導する出し分けは行わない。**
> Appleのガイドラインで禁止されている。

## 状態の保存先

端末ローカル（`SharedPreferences`）。アカウントに紐づける必要はなく、
端末ごとに1回聞ければ十分なため。

| キー | 内容 |
|------|------|
| `app_review_done` | 評価済み（以後出さない） |
| `app_review_dismiss` | 「また今度」の回数 |
| `app_review_next_at` | 次に出してよい日時(ms) |
| `app_review_first_at` | 初回起動日時(ms)。`main.dart` で記録 |
| `app_review_meeting_n` | 会議の完了回数 |

---

## 廃止したもの

**会議の★5段階評価（`rateMeeting`）を画面から削除した。**

- 保存するだけで集計も表示も再利用もされておらず、ユーザーに何も返っていなかった
- 同じ画面で★を2回求めることになり、アプリ評価の導線と競合していた

`MeetingDatasource.rateMeeting` とFirestoreの既存データは残している
（呼び出し元が無いだけ）。
