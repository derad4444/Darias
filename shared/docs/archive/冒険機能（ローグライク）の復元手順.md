# 冒険（ローグライク）機能の復元手順

> 2026-09-16 に削除した冒険（心の迷宮）機能を、あとから戻したくなったときの手引き。
> ここは**アーカイブ**であり、現行の仕様書ではない。現在のアプリに冒険機能は存在しない。

**最終更新日**: 2026-09-17

---

## 要点

**冒険そのもののコードはタグから丸ごと戻せる。** 手作業が要るのは「他の画面につないでいた配線」だけ。

| | 戻し方 |
|---|--------|
| 冒険の画面・ロジック・敵画像・効果音・仕様書 | `git checkout adventure-before-removal -- <パス>` でそのまま取り出せる |
| タブへの組み込み | **判断が必要**。冒険タブがあった位置には今は自分会議が入っている（6タブにするか置き場所を決める） |
| 冒険の中の画面遷移 | **書き換えが必要**。単独ルート方式からタブごとの Navigator 方式に変わった |
| 冒険画面のバナー広告 | **定義ごと消している**。他機能と共用していた実ユニットも削除したので、別名だけ戻しても参照先が無い |
| 日記への反映・キャラ詳細のタブ・設定のリセット・ヘルプ・オンボーディング | 参照を外しただけなので、タグの差分を見ながら戻す |

**タグ時点にアプリ全体を戻すことはできない。** 冒険の削除後に自分会議のタブ化・タブ順変更・全画面でタブバーを出す改修・フレンド導線の整理を積んでいるため。

## 3. そのまま revert してはいけない

`git revert d199da7` では戻せない。削除と同じコミットで**冒険タブの位置に自分会議タブを入れており**、さらにその後タブまわりを大きく作り替えたため。

削除後に入った構造変更:

| コミット | 内容 |
|---------|------|
| `d199da7` | 冒険タブの位置に自分会議タブを差し込んだ（自分会議は単独ルート `/meeting` から**タブの中身**に変わった） |
| `e79e244` | タブの並びを ホーム / 詳細 / フレンド / 自分会議 / 設定 に変更 |
| `abf7420` | **タブごとに独立した Navigator を持つ構造に変更**。タブ内から開く画面は `Navigator.push` で積み、タブバーが残る |

## 4. 復元するときの進め方

1. **冒険のコードを取り出す**
   ```bash
   git checkout adventure-before-removal -- flutter/lib/features/roguelike
   git checkout adventure-before-removal -- flutter/assets/images/roguelike_enemies
   git checkout adventure-before-removal -- flutter/assets/audio/gate_open.mp3
   git checkout adventure-before-removal -- flutter/lib/data/services/sound_effect_player.dart
   git checkout adventure-before-removal -- "shared/docs/game"
   ```

2. **`pubspec.yaml`** に `fl_chart` とアセット `- assets/images/roguelike_enemies/` を戻す

3. **タブをどうするか決める**（ここが一番の判断どころ）
   - 6タブにする: `main_shell_screen.dart` の定数（`homeTabIndex` ほか）に冒険を足し、`IndexedStack` と `_TabItem` の両方に追加する。タブが6つ並ぶ幅で表示が崩れないか要確認
   - 自分会議と入れ替える: 自分会議を単独ルートに戻すことになるが、**タブの中身と同じ画面に単独ルートを持たせない方針**（`app_router.dart` 冒頭のコメント参照）に反するので避ける

4. **冒険の中の画面遷移を今の構造に合わせる**
   削除前は `/roguelike/game` などの単独ルートを `context.push` で開いていた。現在はタブごとの Navigator 方式なので、`Navigator.push(context, MaterialPageRoute(...))` に置き換える。こうするとタブバーが残ったまま冒険の画面を開ける（削除前は開くとタブバーが消えていた）。

5. **広告ユニットを戻す**
   `ad_service.dart` に `scheduleAddTop/Bottom` と `memoTop/Bottom` の実ユニット定義から戻す必要がある（別名だけ戻しても参照先が無い）。ID はタグから取り出す。

6. **日記生成を戻すか決める**
   戻す場合は `generateDiary.js` の `roguelike_runs` 収集と、`templates.js` の `activityDiary(..., roguelikeSummary, ...)` を両方戻す（引数の位置がずれるので注意）。

7. **仕様書を戻す**
   `shared/docs/game/` を復元し、現在の実装に合わせて直す。

## 5. 復元時に必ず確認すること

- **`generateAdventureDiagnosis` は削除前から壊れていた。** `OPTIMIZED_PROMPTS.adventureDiagnosis()` を呼んでいるが、`shared/functions/src/prompts/templates.js` にそのキーは存在せず、実行すると `TypeError` で落ちる。全ダンジョン踏破後の総合診断は削除前の時点で生成できていなかったので、**復元するならプロンプトから実装する必要がある**。

- **Firestore のデータは消していない。** `users/{uid}/roguelike_runs` / `roguelike_clears` / `roguelike_meta/{codex,diagnosis,stamina}` はそのまま残してある。復元すれば以前の冒険の記録がそのまま見える。専用のセキュリティルール・インデックスは元から無く、`users/{userId}/{subcollection=**}` の汎用ルールで守られている。

- **アプリ評価の依頼トリガー**が1つ減っている（「ダンジョン初踏破」）。戻すなら `shared/docs/functions/アプリ評価仕様書.md` もあわせて直す。

- **オンボーディングは5枚**になっている。冒険のスライドを戻すと6枚になり、`logOnboardingSlideView(slideIndex:)` で見ている離脱位置の意味が変わる。
