# DARIAS サポート

DARIAS - AIで自己理解・思考整理 のサポートページです。

## お問い合わせ

アプリに関するご質問、不具合報告、ご要望は以下の方法でお送りください。

### アプリ内から（おすすめ）
設定 → お問い合わせ から送信できます。

### GitHub Issues
[Issues ページ](https://github.com/derad4444/Darias/issues)から報告してください。

返信には通常1〜3営業日いただいております。

## よくある質問（FAQ）

### Q1: パスワードを忘れました
A: ログイン画面のパスワード欄の下にある「パスワードをお忘れの方」から再設定できます。登録したメールアドレスに、DARIASから再設定用のリンクが届きます（有効期限は1時間）。Google・Appleでログインしている場合はパスワードがないため、それぞれのボタンからログインしてください。

### Q2: 性格はどうやって調べるのですか？
A: 堅苦しい性格テストはありません。キャラクターが身近な質問をしてくるので、答えるとバッジが集まり、その答えから性格が分かります。ホーム画面のチャット欄の上にあるバッジのバーをタップすると、好きなバッジの質問から答えられます。

### Q3: 自分の元素（性格タイプ）はいつわかりますか？
A: 第1弾の5つのバッジ（1つのバッジにつき2問、全10問）がそろうと、9つの元素（炎・水・風・土・雷・光・氷・闇・無）から性格タイプが決まり、キャラクターが幼少期に成長します。第2弾の5つのバッジもそろうと、性格がより詳しく分かり、キャラクターが大人に成長します。手に入れたバッジは答え直すこともできます。

### Q4: 自分の長所や苦手なことはわかりますか？
A: 性格タイプが決まると、キャラクター詳細画面に「得意・好き」と「苦手・注意」の2つのタブが表示されます。長所・趣味・元気が出ることなどと、短所・嫌いなこと・苦手な接し方・ストレスを感じる瞬間などが、対になる項目どうし同じ位置に並びます。各項目をタップすると、そうなる理由を見られます。

### Q5: チャット履歴はどこで見られますか？
A: ホーム画面の「履歴」ボタンから確認できます。チャット・会議・日記の履歴を切り替えて見られます。

### Q6: 自分会議とは？
A: 悩みを入力すると、あなたの性格をもとにした「6人の自分」が話し合い、結論と具体的なアドバイスを出してくれる機能です。無料プランでは1回、プレミアムプランでは無制限に使えます。第1弾のバッジがそろって性格タイプが決まると使えるようになります。

### Q7: 友達との相性は見られますか？
A: フレンドを追加すると、友情・恋愛・仕事・信頼の4つの相性を見られます。友達のことを、2人のキャラクターに聞いてみることもできます。

### Q8: フレンドにあだ名を付けられますか？
A: フレンド一覧でフレンドを長押しするか、フレンド詳細の「あだ名を付ける」から付けられます。あだ名はあなたにだけ表示され、相手や他の人には表示されません。同じメニューからあだ名の変更・削除もできます。

### Q9: プレミアムプランでできることは？
A: キャラクターの返答と日記に高品質なAIモデルを使うほか、返答を声で聞けます。自分会議が無制限になり、相性診断・フレンドへの質問も広告なしで使えます。

### Q10: 課金の解約方法
A: iPhoneの「設定」→ 自分の名前 →「サブスクリプション」から解約できます。アプリ内からは解約できませんのでご注意ください。アカウントを削除しても、サブスクリプションは自動では解約されません。

### Q11: 性格の解析をやり直したい
A: 手に入れたバッジは、バッジ一覧から選ぶと答え直せます。すべて最初からやり直したい場合は、設定 →「性格診断をリセット」から実行できます（バッジの回答も消えます）。

### Q12: データを削除したい
A: 設定 →「アカウントを削除」から実行できます。削除後、データは復元できませんのでご注意ください。
