# DARIAS サポート

DARIAS - AIで自己理解・思考整理 のサポートページです。

## お問い合わせ

アプリに関するご質問、不具合報告、ご要望は以下の方法でお送りください。

### アプリ内から（おすすめ）
設定 → お問い合わせ から送信できます。

### GitHub Issues
[Issues ページ](https://github.com/derad4444/Darias/issues)から報告してください。

返信には通常1〜3営業日いただいております。

## よくある質問（FAQ）

### Q1: パスワードを忘れました
A: ログイン画面の「パスワードをお忘れですか？」からリセットできます。登録したメールアドレスにリセット用のリンクが送信されます。

### Q2: 性格はどうやって調べるのですか？
A: 性格テストはありません。AIのキャラクターと話すだけで、会話の内容から性格が自動で解析されていきます。

### Q3: 自分の元素（性格タイプ）はいつわかりますか？
A: 30回以上話すと、9つの元素（炎・水・風・土・雷・光・氷・闇・無）から性格タイプが決まり、キャラクターが幼少期に成長します。100回以上話すと性格がより安定し、キャラクターが大人に成長します。進み具合はホーム画面の成長ゲージで確認できます。

### Q4: チャット履歴はどこで見られますか？
A: ホーム画面の「履歴」ボタンから確認できます。チャット・自分会議・日記の履歴を切り替えて見られます。

### Q5: 自分会議とは？
A: 悩みを入力すると、あなたの性格をもとにした「6人の自分」が話し合い、結論と具体的なアドバイスを出してくれる機能です。無料プランでは1回、プレミアムプランでは無制限に使えます。

### Q6: 友達との相性は見られますか？
A: フレンドを追加すると、友情・恋愛・仕事・信頼の4つの相性を見られます。友達のことを、2人のキャラクターに聞いてみることもできます。

### Q7: フレンドにあだ名を付けられますか？
A: フレンド一覧でフレンドを長押しするか、フレンド詳細の「あだ名を付ける」から付けられます。あだ名はあなたにだけ表示され、相手や他の人には表示されません。同じメニューからあだ名の変更・削除もできます。

### Q8: プレミアムプランでできることは？
A: キャラクターの返答と日記に高品質なAIモデルを使うほか、返答を声で聞けます。自分会議が無制限になり、相性診断・フレンドへの質問も広告なしで使えます。

### Q9: 課金の解約方法
A: iPhoneの「設定」→ 自分の名前 →「サブスクリプション」から解約できます。アプリ内からは解約できませんのでご注意ください。アカウントを削除しても、サブスクリプションは自動では解約されません。

### Q10: 性格の解析をやり直したい
A: 設定 →「性格診断をリセット」から最初からやり直せます。

### Q11: データを削除したい
A: 設定 →「アカウントを削除」から実行できます。削除後、データは復元できませんのでご注意ください。
